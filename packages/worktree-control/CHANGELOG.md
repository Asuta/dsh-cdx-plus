# 更新日志

## 未发布

- 侧边对话转为独立会话时登记原工作树成员，保留项目分组和实际目录；提供可选共享服务，兼容旧侧边会话的归属修复。
- 修复保存环境期间修改操作行导致校验错误丢失：保存时暂时锁定表单，无法定位输入项的错误显示在面板顶部。
- 保存环境时自动忽略完全空白的操作；未填完整或超长的操作按原始序号提示，并定位对应输入框，校验失败保留表单和原配置。
- 修复 Git 操作期间环境命令绕过会话互斥的问题；等待操作完成后重新检查目录和环境，只在登记终端任务时短暂持锁。
- 修复内置终端单独按 Esc 一直等待下一次输入的问题；短暂等待分片按键序列后自动发送，并在停止或退出时清理定时器。
- 环境命令按钮与 Git Diff 的“变更”按钮同组显示，固定在其右侧；未启用 Git Diff 时保留标题栏入口。
- 修复历史对话冷启动时环境命令按钮因会话尚未连接而永久隐藏；等待会话打开后检查，检查失败时提供错误提示和重试入口。
- 在“变更”旁增加当前环境的快捷命令菜单，支持切换环境和直接打开环境管理页。
- 手动操作和工作树自动初始化统一接入内置侧栏终端，实时显示命令与输出、保留结果，支持 Ctrl+C、停止按钮和关闭终端后停止任务。
- 运行中重复点击只定位已有任务；新一次执行使用独立终端。保留沙箱及失败中止语义，并保护正在执行命令的工作树不被本插件切换或清理。
- 手动操作使用多行命令框，支持 Enter 换行、粘贴与保存多行脚本；名称与移除按钮单独排列。
- 环境命令默认失败即停止，Windows PowerShell 同时检查外部程序退出码，避免 Git 拉取失败后继续执行重置和清理。
- 修复 PowerShell 成功命令的 stderr 重定向被误判、catch 中退出码被清零，以及合法 data 块被改写导致解析失败的问题。
- 修复 DSH 0.2.2 普通对话分支不再包含 `parentSession` 后，无法在新工作树中创建分支的问题；改为校验所选位置的继承历史，并分别提示来源不匹配和源对话忙碌。

## 0.1.0

- 新增 DSH 对话内 Git 工作树创建、切换、差异操作、快照归档与恢复。
- 新增仓库级保留数量设置、固定保护、.worktreeinclude 与可选 setup 脚本。
- 新增本地与工作树间的成果交接、原工作树返回、新分支创建与项目 actions。
- 支持自定义工作树根目录；归档对话时快照不再被使用的关联工作树。
