# 模型分组 / Model group labels

在 DSH 输入栏的模型按钮显示“分组名称/模型名称”，并保留原有徽标及推理强度。点击模型右侧的星标即可收藏；收藏项会出现在菜单顶部，原分组中的条目仍保留。收藏记录保存在当前客户端。

在模型菜单中，用 ↑ / ↓ 浏览收藏与原列表，按 Enter 选择模型，按 F2 收藏或取消收藏当前高亮的模型。

Show the selected model as “group name/model name” in the DSH composer, with its original badge and reasoning effort. Star a model to add it to the top of the menu while keeping its original entry. Favorites are saved in the current client.

Use Up / Down to browse both lists, Enter to select a model, and F2 to toggle the highlighted model's favorite status.
