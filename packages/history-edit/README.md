# 编辑历史消息

在已完成的文本或图片用户消息旁点击“编辑”，修改后选择“重新生成”。插件在当前 Session 中追加一个 surface replacement 检查点，隐藏该消息及后续旧路径，再把修改后的内容作为普通用户消息排入同一个 Agent。编辑框会显示原图缩略图，点击可查看大图，也可逐张移除或恢复；原图预览读取失败时显示占位提示。也可用加号按钮、粘贴或拖拽添加图片，纯图片消息可以留空文本直接重新生成。

编辑框中的斜杠候选会合并当前会话注册的原生命令和技能来源，并显示分组及说明。选择动作命令会执行动作、从草稿移除命令 token；选择技能会把原生技能 token 插入并保留草稿。需要参数或弹出交互面板的命令仍应从底部原生输入栏使用。

旧事件仍留在追加式日志中；对话 ID、工作目录和当前右侧面板实例保持不变，因此侧边对话、内置浏览器页面及未提交表单不会因分支切换而卸载。关闭编辑器或命令切换期间，草稿在当前页面生命周期内暂存，回到原消息时可恢复。

目前支持已完成轮次中的单条文本/图片用户消息；不支持裁剪、旋转等图片内容修改。正在运行、有待处理输入、包含文件等其他内容块、或同一轮次含多个用户输入时不提供编辑。编辑请求使用 DSH 身份验证并受同源校验。

DSH 0.2.1-rc.5 的隔离网页版验证使用 deepseek-flash 完成了真实回复与编辑重生成；旧回复从当前对话视图隐藏，右侧内置浏览器的同一 iframe 与未提交 textarea 草稿保持不变。正式桌面版最终验收由用户完成。
