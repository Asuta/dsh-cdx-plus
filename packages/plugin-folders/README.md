# 插件文件夹 · Plugin folders

在官方插件页打开「文件夹」。每个安装包只显示一张卡；点击卡片进入官方详情。拖动卡片到文件夹，或使用卡片的「移动到…」菜单。搜索覆盖全部文件夹。删除文件夹会将内容移回未分组，不会卸载插件。

分类保存在当前 DSH profile 下的插件数据中，以包名识别插件。插件升级不会改变归属。此页不更改启停状态；请在官方详情中管理。

Open **Folders** on the Plugins page to organize installed bundles. Drag a package onto a folder or choose **Move to…**. Removing a folder returns its contents to Ungrouped.
